06 · AI system map

Rules first — any AI must beat them in replay

The MVP makes no LLM calls. A frozen, deterministic engine (Stack Generation Rules v0.2) builds every Stack. The LLM arrives later for three jobs only — explain, adapt and reflect — and never selects a video or enforces a constraint.

Scenario→Eligibility gate (fail closed)→Hard filters→Score eligible videos→Pack 1–3 videos→Order low → high intensity→Revalidate→Stack or NO_VALID_STACK

09 · AI feature deep dives

Three future LLM jobs: explain, adapt, reflect

Each is tested against the frozen rules baseline. None is in the Demo Day build.

A · Explain

LLM from reason codes

Hypothesis: a short explanation written only from the engine's reason codes lifts swap-free starts.

  • Every sentence maps to a reason code; no outcome claims
  • Template fallback above a daily budget; cached per Stack
  • Eval: faithfulness audit + A/B on swap-free starts
  • Cost: ~0.1p per Stack
B · Adapt

Weekly adaptive coach

Hypothesis: turning a learned profile into next week's session shapes lifts week-4 and week-8 return.

  • Outputs scenario inputs only — never names a video
  • Profile visible and editable; no health inference
  • Eval: return with vs without; small paid cohort; LLM vs rules-only planner
C · Reflect

Progress narration

Hypothesis: honest narration from session logs shows progress YouTube never shows.

  • Two lines and one suggestion a week
  • No causal claim unless the confounder is controlled
  • Eval: claim-level audit; week-4 return with vs without
10 · Evaluation plan

Three layers, each gating the next

A 0% violation rate proves the engine obeyed its tags — not that the tags were right.

LayerQuestionMethodBar
0. Constraint testDid the engine obey the tags?Automated test on every rules_version0% violations
1. Tag accuracyAre the tags right?Golden set: frozen 50 videos, two blind reviewers, adjudicationRecall + error direction for safety fields; ~90% descriptive
2. Stack coherenceWould you press play?Adversarial n = 30 Stacks with target users, pass/fail rubric24–27 passes = pilot-ready; ≤18 = stop and fix
In productDoes it work for real?Swaps by position, completion, returnSwap-free ≥70%, first-Stack completion ≥60%, week-2 return ≥40%, time to play <60 s
Thresholds are written before results arrive, one rule changes per run, and completion alone is not accuracy — optimising it would push shorter, easier sessions. At n = 50, 90% accuracy carries about ±9 points, so no external accuracy claim until ~200.

13 · Why Fit My Day, not YouTube

YouTube optimises for watch time. We optimise for workouts finished.

Trigger

“I want to work out but don't know what.” Under 60 seconds vs 5+ minutes.

Action

Two required choices (time, body part), two optional.

Reward

A session that fits today, guaranteed filters, one-tap replay.

Investment

History and saved Stacks live here; each calibrated release improves Stacks for everyone.

North Star: completed Stacks per weekly active user. Guardrails: no streaks or guilt — a missed session feeds next week's plan, never a penalty.

14 · Business model

Free MVP; test whether users pay for memory

Free

Today's session, swaps, filters, History, Discover and sharing.

Premium candidates

Weekly adaptive coach, unlimited personalised Stacks, progress narration — tested with a small paid cohort in Phase 3.

Never sold

Ad removal or offline playback — blocking ads breaks YouTube's terms.

Unit cost: zero LLM cost in the MVP; ~£0.013 per user per month once explanations launch. Human review is already 80%+ of operating cost, so review efficiency matters more than model price.
